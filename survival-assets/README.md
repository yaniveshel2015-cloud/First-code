# ערכת הישרדות למצגת 🏝️🔥

איורים מצוירים בסגנון "הישרדות" על אי טרופי, לשימוש במצגות (PowerPoint, Google Slides, Canva, Keynote).
כל האיורים מקוריים ונוצרו במיוחד בשביל הערכה הזאת, כך שאפשר להשתמש בהם בחופשיות.

**כדי לראות הכול בבת אחת, פתחו את `gallery.html` בדפדפן** (אחרי שחילצתם את ה-ZIP), או הסתכלו על התמונות בתיקייה `previews/`.

## טיפים לבניית המצגת
- **הוספת תמונה:** הוספה ← תמונות ← בחירת קובץ PNG. לכל הקבצים, חוץ מהרקעים, יש רקע שקוף, כך שאפשר להניח אותם ישר על הרקע.
- **רקע לשקופית:** לחיצה ימנית על השקופית ← "עיצוב רקע" ← "מילוי תמונה" ← בחירת קובץ מ-`02-backgrounds`.
- **להפוך דמות או בועה לצד השני:** סידור ← סובב ← "הפוך אופקית". כך הדמות מצביעה או מסתכלת לצד השני.
- **טקסט בתוך בועה או שלט:** מוסיפים תיבת טקסט מעל הבועה, ואז מסמנים את שתיהן ולוחצים Ctrl+G כדי לקבץ אותן ולהזיז אותן יחד.
- **אנימציה:** כדאי לתת לדמויות אנימציית כניסה "הקפצה" (Bounce), לבועות "דהייה" (Fade) או "הגדלה" (Zoom), ולפסל החסינות אנימציית הדגשה "פעימה" (Pulse).
- **דמות שמשנה הבעה:** שמים את אותה דמות בשתי שקופיות רצופות עם שתי תנוחות שונות (למשל `00-standing` ואחריה `03-shocked`) ומשתמשים במעבר "Morph" או "דהייה". כך נראה כאילו הדמות מגיבה.
- **רעיונות לשקופיות:** "פתיחת פתקי ההצבעה" (כד הצבעות עם פתק ריק שכותבים עליו שם), "הלפיד כבה" (לפיד כבוי למי שהודח), "מצאתי פסל חסינות!" (הפסל הזוהר), ו"מפת המשימה" (מפת אוצר עם השלבים).

## יצירה מחדש
כל האיורים נוצרים מקוד שנמצא בתיקייה `tools/`. כדי לשנות צבעים או להוסיף דמויות, עורכים את הקבצים שם ומריצים:
```
node tools/build.js     # יוצר את כל קובצי ה-PNG וה-SVG
node tools/preview.js   # יוצר את gallery.html ואת תמונות התצוגה המקדימה
```
(צריך Node.js ו-Playwright.)
