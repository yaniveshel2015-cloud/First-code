# First-code

## בונים מילים

משחק לימוד אנגלית לילדים: גוררים אותיות אל שורת הכתיבה ומרכיבים מילה.
כשנוצרת מילה, המשחק מקריא אותה באנגלית ומקפיץ תמונה של המשמעות שלה, יחד עם התרגום לעברית.

### איך משחקים

- גוררים אות מהלוח אל השורה, או פשוט לוחצים עליה. אפשר גם להקליד במקלדת.
- אפשר לגרור אותיות בתוך השורה כדי לשנות את הסדר. לחיצה על אות בשורה מסירה אותה.
- לחיצה על התמונה או על "הקראה" משמיעה את המילה שוב.
- "רעיון" מציע מילה חדשה להרכיב.

### איך מפעילים

פותחים את `index.html` בדפדפן (Chrome, Safari, Edge או Firefox). אין צורך בהתקנה.
ההקראה משתמשת בקול האנגלי המובנה במכשיר.
המשחק בוחר את הקול הטבעי ביותר שיש במכשיר, ואפשר להחליף אותו בתפריט "קול ההקראה" שבתחתית המסך.

### איך מוסיפים מילים

בתוך `index.html` יש רשימה בשם `WORDS`. כל שורה היא מילה בפורמט:

```
word|תמונה (אימוג'י)|תרגום לעברית
```
